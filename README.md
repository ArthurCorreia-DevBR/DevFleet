# 🚚 DevFleet

API REST para gerenciamento de frotas, desenvolvida com Java e Spring Boot.

## Sobre o projeto

O DevFleet é um projeto de estudo e portfólio que tem como objetivo desenvolver uma solução para centralizar o gerenciamento de frotas de veículos, motoristas, viagens, abastecimentos e manutenções.

A proposta é trabalhar com regras de negócio reais, garantindo a consistência das operações e o controle das informações da frota.

## Funcionalidades planejadas

- Gerenciamento de veículos.
- Gerenciamento de motoristas.
- Registro e acompanhamento de viagens.
- Controle de abastecimentos e consumo de combustível.
- Gerenciamento de manutenções.
- Histórico operacional da frota.
- Validação de regras de negócio.
- Autenticação e controle de acesso.

## Tecnologias

- Java
- Spring Boot
- Spring Web
- Spring Data JPA
- Hibernate
- PostgreSQL
- Lombok
- Bean Validation
- Swagger / OpenAPI
- JUnit 5 e Mockito
- Spring Security e JWT
- Docker

*As tecnologias serão introduzidas gradualmente durante o desenvolvimento.*

## Status do projeto

🚧 Em desenvolvimento.

Atualmente, o projeto está na fase inicial de estruturação. As funcionalidades serão implementadas progressivamente, começando pela modelagem do domínio e estruturação das entidades.

## Objetivo

Desenvolver uma aplicação backend que permita aprofundar conhecimentos em Java, Spring Boot, arquitetura de software, persistência de dados, APIs REST, testes automatizados e boas práticas de desenvolvimento.
